# 数据源格式说明

Marginalia 读取的是一个或多个**本地目录**，在里面递归查找 `.md` 文件，把符合格式的笔记解析成书籍。它对这些目录**只读**，不会修改或新增任何文件。

笔记格式与 weread2obsidian 一类工具导出的微信读书笔记一致。只要按下面的格式写，手写的 Markdown 也能被识别。

## 目录结构

```
08微信读书/                 ← 在「数据源」里填这一层的绝对路径
├─ 文学/
│  ├─ 挪威的森林.md
│  └─ 雪国.md
├─ 个人成长/
│  └─ 断舍离.md
└─ 某本没分类的书.md
```

- 子目录可以任意嵌套，以 `.` 开头的目录（如 `.obsidian`、`.trash`）会被跳过。
- 只处理 `.md` 文件；不符合格式的文件会被静默忽略，所以数据源直接指向整个 Obsidian 库也没问题，只是扫描会慢一点。
- 笔记的 frontmatter 里没写 `category` 时，用它所在的**第一级子目录名**作为分类；直接放在根目录下的归为「未分类」。
- 可以添加多个数据源目录，书籍会合并展示，按 `created` 从新到旧排序。

## 文件格式

每本书一个 Markdown 文件，由两部分组成：开头的 YAML frontmatter，和后面的正文。

### Frontmatter

只有两个字段是必须的，缺了任何一个，这个文件就不会被当成书：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `doc_type` | 是 | 固定写 `weread-highlights-reviews` |
| `title` | 是 | 书名 |
| `bookId` | 否 | 微信读书的书籍 ID，用作封面缓存的文件名，建议填写 |
| `author` | 否 | 作者；开头的 `【日】` 这类国籍标记会在显示时去掉 |
| `cover` | 否 | 封面图片 URL，首次访问时下载并缓存到 `data/covers/` |
| `category` | 否 | 分类，用 `-` 分隔层级，如 `文学-外国文学`；筛选栏只用第一级 |
| `readingStatus` | 否 | 阅读状态：`1` 想读、`2` 在读、`3` 读过、`4` 读完 |
| `finishedDate` | 否 | 读完日期；没填 `readingStatus` 时，有这个字段就算「读完」，否则算「在读」 |
| `created` | 否 | 创建日期，用于排序和时间轴 |
| `readingDate` | 否 | 最近阅读日期 |
| `progress` | 否 | 阅读进度，原样显示，如 `7%` |
| `readingTime` | 否 | 阅读时长，原样显示，如 `0小时12分钟` |
| `isbn` | 否 | ISBN |
| `noteCount` / `reviewCount` | 否 | 笔记数 / 书评数 |
| `tags` | 否 | 标签，块式列表 |

注意解析器是一个很简单的 YAML 子集：只支持 `key: value` 单行值，以及 `key:` 下面缩进的 `- item` 列表。不支持多行字符串、行内数组 `[a, b]` 或嵌套对象。值两边的引号会被去掉，所以 `bookId: "25066071"` 和 `bookId: 25066071` 效果一样。

### 正文

```markdown
![cover|120](https://.../cover.jpg)

### 断舍离
**山下英子**

个人成长-人生哲学 · 湖南文艺出版社 · 2019-01-01 00:00:00

划线 4 · 笔记 0 · 最近阅读 2022-09-03

---

## 推荐序一 做物质的减法，精神的加法

> “世界上最让人感动的，是遥远的相似性。”

> 另一条划线。

## 第一章

> 第一章里的划线。

## 书评

这里写书评，可以多行。
```

按顺序解析：

1. **出版行（可选）**：形如 `分类 · 出版社 · YYYY-MM-DD`，分隔符是 ` · `（空格、中点、空格），日期必须是 `YYYY-MM-DD` 开头。从这里取出版社和出版日期。
2. **第一条 `---` 水平线**：它之前的内容（封面、书名、作者、统计行）都只是给 Obsidian 看的，解析器跳过。**这条水平线是必需的**，没有它就读不到任何划线。
3. **章节**：任意级别的 Markdown 标题（`#` 到 `######`）开始一个新章节，标题文字就是章节名。
4. **划线**：以 `>` 开头的每一行算一条划线，行内多余空白会被压缩。出现在第一个标题之前的划线归到「正文」章节。没有划线的章节不显示。
5. **书评**：标题正好是 `书评` 的章节，下面的所有非空行合并为书评文字，不算划线。

## 最小示例

下面这个文件就能被识别成一本书：

```markdown
---
doc_type: weread-highlights-reviews
title: 我的测试书
author: 某某
category: 文学
created: 2026-11-04
---

---

## 第一章

> 这是一条划线。
```

## 常见问题

- **加了目录但显示 0 本书**：先看 frontmatter 有没有 `doc_type: weread-highlights-reviews` 和 `title`，以及文件开头是不是 `---`（前面不能有空行）。
- **书出来了但没有划线**：检查正文里是否有那条 `---` 水平线，以及划线是不是以 `>` 开头。
- **封面不显示**：确认 `cover` 是可以直接访问的图片 URL，并且填了 `bookId`；缓存文件在 `data/covers/<bookId>.jpg`，删掉就会重新下载。
- **改了笔记没刷新**：文件的修改时间或大小变化后会自动重新解析，刷新页面即可。
